💡 Comment obtenir les clés ?
① Clé Groq (recommandée, la plus généreuse) : console.groq.com/keys → « Create API Key » (gratuit, sans carte, 14 400 requêtes/jour, très rapide).
② Clé Gemini : aistudio.google.com/apikey → « Create API key » (gratuit, ~1 500 req/jour).
③ Worker : dash.cloudflare.com → Workers & Pages → Create Worker → collez worker.js → Settings → Secrets → GEMINI_API_KEY → Deploy → copiez l'URL + /api/chat.
Priorité automatique : Worker > Groq > Gemini. Après « Enregistrer l'IA », rechargez la page.
